📌 About PawCare

PawCare is a modern pet-care management platform created to make everyday pet care easier and more organized.

The platform provides pet owners with a centralized place to manage their pets, keep track of veterinary appointments, receive vaccination and medicine reminders, explore pet-care recommendations, and access pet products.

The project was developed as an internship/project application with a focus on creating a professional, user-friendly and responsive web experience.

🔐 Supabase Integration

PawCare is designed to use Supabase for backend functionality.

Supabase can provide:

- 🔑 User authentication
- 👤 User profiles
- 🐕 Pet records
- 🩺 Veterinary information
- 📅 Appointment records
- 🔔 Reminder management
- 🗄️ PostgreSQL database

The frontend communicates with Supabase to store and retrieve application data.
